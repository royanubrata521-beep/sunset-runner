# 🌅 Sunset Runner

A simple 2D endless runner game built as a fun web development project.

## 🎮 About the Game

Sunset Runner is a lightweight endless running game where the player needs to avoid obstacles and keep running for as long as possible.

I built this project to practice my HTML skills and understand how basic game mechanics work in a browser.

## ✨ Features

- 🏃 Endless running gameplay
- 🎯 Simple player controls
- 🚧 Obstacles to avoid
- 🏆 Score-based gameplay
- 🌅 Simple sunset-themed design
- 💻 Runs directly in a web browser

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open `sunset runner.html` in any modern web browser.
3. Start playing and try to get the highest score!

## 📚 What I Learned

Through this project, I practiced basic web development concepts, game logic, user interaction and browser-based programming.

## 🔮 Future Improvements

I would like to improve the game further by adding better animations, sound effects, more obstacles, difficulty levels and a better scoring system.
